# Icon study (2026-11-16)

Fourteen app icon directions, rendered by `gen.py` (Pillow) and presented with `build_page.py`.
Published page: https://claude.ai/artifact/9V4szPPjNwKRHhjAYmnZ8Y (private to the owner).
The shipped icon is option 01 (Silver Dial), generated by `scripts/make_icon.py`.

Regenerate: `python3 gen.py out && python3 build_page.py out icon-study.html`. `renders/` holds the 180 px versions.
